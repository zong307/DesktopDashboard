# DesktopDashboard UI/UX 设计规范

## 设计理念

遵循 **Apple Human Interface Guidelines**，追求：
- **简洁** — 去除一切不必要的装饰
- **自然** — 半透明、模糊效果营造空间感
- **克制** — 信息密度适中，留白充足
- **一致** — 统一的视觉语言贯穿始终

## 色彩规范

### 主色板

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | `rgba(255,255,255,0.85)` | 毛玻璃白底 |
| 主文字 | `#1d1d1f` | Apple 深灰 |
| 次要文字 | `#86868b` | Apple 浅灰 |
| 强调色 | `#007AFF` | Apple 蓝 |
| 成功 | `#34C759` | 绿色 |
| 警告 | `#FF9500` | 橙色 |
| 错误 | `#FF3B30` | 红色 |

## 动画规范

### 持续时间

| 类型 | 时长 | 缓动 |
|------|------|------|
| 快速 | 0.15s | ease-out |
| 标准 | 0.3s | ease-in-out |
| 慢速 | 0.5s | ease-in-out |

### 动效列表

| 场景 | 动效 |
|------|------|
| 窗口显示 | 淡入 + 轻微上移 |
| Toast 提示 | 淡入 → 保持 2s → 淡出 |
| 菜单展开 | 向上滑入 + 淡入 |
| 状态指示器 | 颜色过渡 |

## 布局规范

### 窗口尺寸

- 默认：280×180px
- 最小：240×160px
- 最大：320×200px

### 内容布局

```
┌──────────────────────────────┐

│                              │
│ LAN IP                       │
│ 192.168.1.100    📋          │  ← 内容块
│                              │
│ Public IP                    │
```

### 响应式原则

- 窗口大小固定，内容自适应
- IP 值右对齐，标签左对齐
- 复制按钮始终在 IP 值右侧

## 交互反馈

### 鼠标悬停

| 元素 | 反馈 |
|------|------|
| 复制按钮 | 显示图标 + 背景色变化 |
| 菜单项 | 蓝色高亮背景 |
| 窗口 | 无变化（保持简洁） |

### 点击反馈

| 操作 | 反馈 |
|------|------|
| 复制 IP | 显示"已复制"Toast |
| 菜单选项 | 立即执行，无动画 |
| 拖拽窗口 | 鼠标样式变化 |

### 状态指示

| 状态 | 指示器颜色 |
|------|-----------|
| 正常 | `#34C759`（绿） |
| 警告 | `#FF9500`（橙） |
| 错误 | `#FF3B30`（红） |

## 无障碍规范

- 文字与背景对比度 ≥ 4.5:1
- 可点击元素尺寸 ≥ 24×24px
- 支持键盘导航（Tab 键）
- 语义化标签（label/value 分离）
